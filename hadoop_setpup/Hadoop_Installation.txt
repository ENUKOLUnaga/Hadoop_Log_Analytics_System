7.Move Hadoop to E drive
-------------------------
Purpose: placing Hadoop permanently in E: Drive and moving for configuration

commands:
mv ~/hadoop-3.3.6.tar.gz /mnt/e/
cd /mnt/e
tar -xvzf hadoop-3.3.6.tar.gz
mv hadoop-3.3.6 hadoop

8.create Hadoop data directories by cleaning old data
------------------------------------------------------
purpose: remove old data, create new directories, check locations, list contents.
command:
sudo rm -rf /mnt/d/hadoop/data
mkdir -p ~/hadoop-data/namenode
mkdir -p ~/hadoop-data/datanode
pwd
ls

output:
shows current directory

9. configure Hadoop:
--------------------
purpose: configure Hadoop by defining default file system (fs.defaultFS). setting to hdfs

command:
nano /mnt/e/hadoop/etc/hadoop/core-site.xml

<configuration>
  <property>
    <name>fs.defaultFS</name>
    <value>hdfs://localhost:9000</value>
  </property>
</configuration>

Purpose: The hdfs-site.xml file defines HDFS settings such as replication and the storage directories for NameNode and DataNode.

command:
hdfs-site.xml nano /mnt/d/hadoop/etc/hadoop/hdfs-site.xml <configuration>
 <property> 
<name>dfs.replication</name> <value>1</value> </property> 
<property> 
<name>dfs.namenode.name.dir</name>
 <value>file:/mnt/d/hadoop/data/namenode</value> </property> 
<property> <name>dfs.datanode.data.dir</name> <value>file:/mnt/d/hadoop/data/datanode</value> </property> 
</configuration>

10. Set Hadoop Environment Variables
-------------------------------------
Purpose: make Hadoop accessible to terminal

commands:
nano ~/.bashrc
Add at the bottom:
export JAVA_HOME=/usr/lib/jvm/java-8-openjdk-amd64
export HADOOP_HOME=/mnt/d/hadoop
export PATH=$PATH:$HADOOP_HOME/bin:$HADOOP_HOME/sbin
reload:
source ~/.bashrc
hadoop version

11.Format NameNode:
-------------------
Purpose: Initializing and formating the NameNode storage directory for first-time HDFS setup.

command:
hdfs namenode -format

12. Install & Configure SSH (Required for Hadoop)
-------------------------------------------------
Purpose: The purpose of installing and configuring SSH is to enable secure, password-less communication required for Hadoop services to start and manage cluster operations.

command:
sudo apt install -y openssh-server
sudo service ssh start
sudo service ssh status

13.Enable Password less SSH
---------------------------
Enabling passwordless SSH allows Hadoop to start NameNode, DataNode, and other daemons without manual password entry.

command:
ssh-keygen -t rsa -P "" -f ~/.ssh/id_rsa
cat ~/.ssh/id_rsa.pub >> ~/.ssh/authorized_keys
chmod 600 ~/.ssh/authorized_keys
ssh localhost
exit

14.Start HDFS
--------------
Purpose: starting the Hadoop Distributed File System by launching the NameNode, DataNode, and Secondary NameNode services.

command:
